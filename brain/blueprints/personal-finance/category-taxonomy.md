# Category Taxonomy

Use these categories when importing or updating transactions. Prefer the most
specific match. Ask before inventing a new category.

| Category | Examples |
|---|---|
| Housing | Rent, mortgage, rates, body corporate |
| Groceries | Supermarket, butcher, greengrocer |
| Transport | Fuel, public transit, parking, rideshare |
| Utilities | Power, water, internet, mobile |
| Entertainment | Streaming, hobbies, events |
| Dining | Cafes, restaurants, takeaways |
| Health | Pharmacy, GP, dentist, gym |
| Insurance | House, contents, car, health, life |
| Savings | Transfers to savings or investments |
| Income | Salary, refunds, reimbursements |
| Transfer | Transfers between own accounts |
| Other | Anything that does not fit above |

Sign convention: negative amounts are spend, positive amounts are income.
Default currency is NZD.
